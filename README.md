# Casa Fresca theme: static preview

A static render of the [Casa Fresca Shopify theme](https://github.com/JustUseFlint/casa-fresca-shopify-theme). The theme's own Liquid is rendered with LiquidJS against the store's public product data (fetched Nov 10, 2026).

The cart runs in the browser (localStorage) using the same JSON shape as Shopify's AJAX Cart API. Checkout, accounts and form sending are disabled because this is a preview. Filters, sorting and search are client-side stand-ins for Shopify's server-side versions.
